Context

A platform where errors are not an option

Cannect is an intelligent traceability tool built for a biotechnology company operating in a heavily regulated B2B environment. The platform handles the tracking of biological samples, processes, and compliance documentation: the kind of domain where precision, auditability, and workflow clarity are non-negotiable.

The users are technical professionals like laboratory staff, quality assurance teams, and operations managers working under strict regulatory requirements. Every interaction with the platform carries real consequences, where an unclear interface is not just frustrating but creates direct compliance risk.

Problem

Too much information, too little clarity

The existing interface had accumulated significant complexity over time. Dense information layouts, inconsistent patterns, and workflows did not match how users actually performed their tasks across different touchpoints. The most critical flows were taking users approximately 30 seconds to complete steps that should have been near instant.

In a compliance-driven environment, this was not just a UX problem. Cognitive overload increases error rates, slow task completion affects operational throughput, and unclear validation feedback makes it harder for users to trust the system.

The core challenge

How do you simplify a genuinely complex domain without removing the precision and control that technical users depend on? The goal was clarity without oversimplification: making the interface faster across desktop and mobile devices without hiding information that matters.

My role

End to end design ownership

As UX/UI Lead, I owned the design process from research to final handoff across web and native mobile platforms:

  • Coordinating and facilitating UX research and benchmarking at multiple project stages
  • Defining the information architecture for the redesigned traceability flows across web and mobile viewports
  • Designing native mobile patterns for on the go sample tracking and responsive web layouts for desktop workstations
  • Designing and iterating wireframes through to high fidelity prototypes
  • Validating solutions with users before finalising design decisions
  • Aligning design decisions with technical constraints, mobile platform guidelines, and accessibility goals
  • Collaborating with engineering on handoff, component systems, and multi-platform implementation

Process

Research first, then design

The work began with a preliminary design phase: mapping multi-device user flows, defining information architecture, and stress-testing traceability requirements before making UI decisions. That structural groundwork, combined with research sessions at mid-process and pre-launch, shaped every design decision that followed.

Benchmarking informed structural decisions: how comparable platforms in regulated industries handle dense information, how native mobile UI patterns support complex data entry in the field, and where we needed to deviate from convention.

User flow mapping, traceability task analysis

Key design decisions

What we changed and why

Decision 01

Progressive disclosure and multi-device strategy

The original interface displayed all available information simultaneously. We restructured around progressive disclosure, surfacing only what users needed at each step on both desktop and native mobile views. This reduced visual noise while ensuring full data access when needed.

Decision 02

Responsive web architecture and native mobile patterns

We established a dual interface strategy: a high density, highly scannable web platform for desktop analysis alongside a streamlined native mobile app optimized for quick scanning and sample logging on the go. Both environments adhered strictly to WCAG 2.2 accessibility standards and shared a unified visual taxonomy.

Decision 03

Explicit, context-aware validation states

In a compliance environment, users need to know not just that something is wrong, but specifically what to do about it. We designed explicit, real-time validation feedback across web and mobile that guided users to resolution rather than just flagging errors.

Final solution

Precision without friction across every touchpoint

Final Cannect interface traceability dashboard

The redesigned Cannect platform maintains the full complexity of the domain whether accessed from a workstation or a mobile device. All data, validation loops, and traceability requirements remain intact while making that complexity navigable. Tasks that previously required users to hold multiple pieces of information in their heads simultaneously now follow a clear, step by step structure.

The design system established during this project provided a consistent foundation for future development: scalable web and mobile components that engineering could implement faithfully and that the design team could extend without divergence.

Outcome

83% faster with maximum precision

The primary success metric was task completion time on the critical traceability workflow. It went from approximately 30 seconds to 5 seconds, representing an 83% reduction. This is a meaningful improvement in an operational context where the same action is repeated many times daily across different physical work settings.

Beyond the quantitative result, user satisfaction increased measurably. Users reported feeling more confident in the interface, feeling not just faster but more in control. In a compliance environment, that sense of clarity and control is a core product quality.

Reflection

What this reinforced

This project reinforced something I believe strongly: in complex, technical B2B domains, the most important design work is structural information architecture and workflow design across all user touchpoints, not visual surface. Getting the multi-platform structure right was what drove the 83% performance improvement, and the visual layer naturally followed from that.
